# Morongwe Molaba — Portfolio

A single-page personal portfolio with a robotics theme: an animated circuit
network in the hero, a friendly SVG robot, a typewriter role rotator, and a
light/dark theme that follows the visitor's system setting. No build step and
no dependencies — just static HTML, CSS, and JavaScript.

## Structure

```
morongwe-portfolio/
├── index.html        # page content
├── css/
│   └── styles.css    # all styling + design tokens
├── js/
│   └── main.js       # rotator, scroll-spy, canvas animation
└── README.md
```

Fonts (Chakra Petch, IBM Plex Sans, IBM Plex Mono) load from Google Fonts, so
the page needs an internet connection to show them; everything else is local.
